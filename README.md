# loops

## Overview
loops is a web-based application designed to help users build and maintain positive habits by tracking their daily progress. Whether you're trying to exercise more, read regularly, or learn a new skill, this application empowers you to stay consistent and accountable.

![](/docs/screenshot-1.png)

## Features

### Core Features
- **Custom Habit Creation**: Define your habits with custom names, frequencies, and goals.
- **Daily Progress Tracking**: Mark your habits as completed each day.
- **Progress Reports**: View weekly, monthly, and overall progress with visual charts.
- **Streaks and Rewards**: Earn streaks and rewards for consecutive days of completing habits.

### Additional Features
- **Reminders**: Set reminders to ensure you don’t forget to track your habits.
- **Tagging and Organization**: Organize habits using tags or categories.
- **Dark Mode**: Choose between light and dark themes for optimal viewing.
- **Responsive Design**: Access the application on desktop, tablet, or mobile devices.

## Getting Started

### Prerequisites
- Modern web browser (e.g., Chrome, Firefox, Safari, Edge)
- Internet connection

### Installation
This application is hosted online. No installation is required.

If you prefer to run it locally:
1. Clone the repository: `git clone https://github.com/yourusername/loops.git`
2. Navigate to the project directory: `cd loops`
3. Install dependencies: `npm install`
4. Start the development server: `npm start`
5. Open `http://localhost:3000` in your browser.

### Usage
1. Sign up or log in to your account.
2. Create your first habit by clicking the **Add Habit** button.
3. Set your habit frequency (e.g., daily, weekly).
4. Track your progress by marking habits as completed each day.
5. View your streaks and analyze progress through the dashboard.

## Technologies Used
- **Frontend**: React, HTML, CSS, JavaScript
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Charting**: Chart.js
- **Authentication**: JSON Web Tokens (JWT), OAuth
